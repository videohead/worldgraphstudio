# Installation

## Recommended For Creators

### WordPress Studio

The easiest way to run World Graph Studio.

- Free
- Runs locally
- No hosting required
- Beginner-friendly

### LocalWP

Another excellent option for local development and creative work.

---

## Recommended For Power Users

### Docker

Run World Graph Studio inside containers and integrate with ComfyUI, local LLMs, MCP servers, and additional services.

---

## Developer Options

- LAMP
- MAMP
- XAMPP
- Lando

These are typically best suited for developers.

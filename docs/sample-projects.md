# Sample Projects

The bundled Little Red Riding Hood project is the quickest way to see how a
finished Story Graph fits together. It contains familiar story material, so you
can focus on the structure instead of inventing content while learning.

## Choose a sample

The recommended full sample is:

`about/example-workflow/little-red-riding-hood-full-featured.worldgraph.json`

It demonstrates a Project, Story World, Characters, Locations, Props,
Organization, Episode, Scenes, Shots, Sounds, Assets, an Editorial Artifact,
sequences, taxonomies, and relationships.

A smaller compatibility fixture is also included at:

`about/example-workflow/little-red-riding-hood.worldgraph.json`

Most users should begin with the full-featured sample.

## Import it

1. Sign in to WordPress as an administrator.
2. Open **World Graph Studio > Import**.
3. Choose the full `.worldgraph.json` file.
4. Leave overwrite disabled for your first import.
5. Select **Create Import Preview**.
6. Review the project name and record counts.
7. Check the confirmation box and select **Confirm and Import Project**.
8. Read the import report, then open the new Project.

Canonical World Graph Studio JSON is validated locally and does not require an
AI Connection.

## Explore the result

Start at the Project and open related records in this order:

1. Story World — the shared setting and rules.
2. Characters and Locations — the people and places used by the story.
3. Scenes — narrative events in order.
4. Shots and storyboard records — production intent for each Scene.
5. Assets — media connected to the story and its provenance.
6. Editorial Artifact — downstream editing and delivery information.

Try editing a description, adding a new Prop, and linking it to a Scene. You can
delete the imported records later or restore your WordPress backup if you want
to repeat the exercise.

For a more detailed walkthrough, use the
[full example workflow](../about/example-workflow/USER_GUIDE.md).

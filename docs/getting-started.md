# Getting Started

World Graph Studio helps you organize a story as a connected world rather than
as a collection of unrelated documents. Characters can be connected to
locations, scenes can be connected to shots, and generated or uploaded assets
can stay attached to the creative decisions that produced them.

It runs inside WordPress, but you do not need to be a WordPress developer to
use it. Think of WordPress as the application that stores your project and
provides its editing screens.

## The simplest path

1. Follow the [installation guide](installation.md) to create a WordPress site
   and install World Graph Studio.
2. Open **World Graph Studio > Setup** in the WordPress dashboard. You may skip
   every AI and media-provider option at first.
3. Import the bundled [sample project](sample-projects.md), or create a new
   Project and Story World.
4. Open the Project and add or edit its Characters, Locations, Scenes, and
   other records.
5. Connect records as your world develops. Those connections form the
   [Story Graph](world-graph.md).
6. Use [story import](story-import.md), [story export](story-export.md),
   [AI assistance](ai-assistants.md), or [generation workflows](generation-workflows.md)
   when you need them.

## What you need—and what you do not

World Graph Studio requires WordPress and the free Secure Custom Fields plugin.
It does not require an AI account, API key, generation service, or paid
subscription for ordinary story planning and asset management.

Optional services can add AI analysis or media generation. These services may
have separate accounts, prices, usage limits, and privacy terms. Start without
them if you want to learn the workspace before choosing a provider.

## Understanding the WordPress dashboard

After signing in, the dark menu on the left is the main navigation. World Graph
Studio adds its own section there. A WordPress “post” is simply a saved record;
World Graph Studio uses different record types for Projects, Characters,
Locations, Scenes, Shots, Assets, and more.

The **Media Library** stores uploaded and generated images, audio, video, and
source documents. **Plugins** is where an administrator activates World Graph
Studio and its required dependency. You normally do not need to change themes,
pages, or blog settings to work on a private creative project.

## A good first session

Import the Little Red Riding Hood sample, open its Project, and follow its
relationships to a Character, Location, Scene, and Shot. Edit a description,
add one new record, and connect it to an existing Scene. This makes the Story
Graph easier to understand than starting with a blank project.

If something is unclear, see the [FAQ](faq.md). Developers and advanced site
operators can use the [technical documentation](../about/README.md).
